## Resume Studio

This repository includes **Resume Studio**, a small local application I use to maintain the résumé. It provides structured editing, live 3D/PDF/page previews, project and experience management, themes, validation, backups, and an SEO/pages workspace.

The 3D experience, readable web pages and PDF all come from the same résumé content so they stay consistent.

## The experience

The main web version is an explorable developer universe rather than a conventional scrolling résumé. It includes layered 3D navigation, multiple visual themes, guided exploration, recruiter-friendly reader mode, shareable deep links, keyboard commands, accessibility/reduced-motion support, and adaptive rendering for lower-powered devices.

For visitors who prefer traditional navigation, the site also exposes fast, readable pages for projects, experience, skills, education and contact.

> The PDF is the concise printable version; the readable pages are the conventional web version; the 3D experience is the interactive version.
